# Self-hosted fonts

Libre Caslon Text (400/700 Latin) from @fontsource/libre-caslon-text 5.3.0; Lato (400/700 Latin) from @fontsource/lato 5.2.7.

Downloaded using npm pack with normal registry integrity and TLS verification. These are static font assets; package manifests and lockfiles are unchanged. The SIL Open Font Licenses are included alongside the files.
